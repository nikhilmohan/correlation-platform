# Offline basemap assets — `europe.json`, `graticule.json`, `cities.json`

These are the committed, offline-only basemap assets used by the geo-site map
(`src/app/topology/geo-site-map.component.ts`). They are served as static assets
(`angular.json` globs `public/**`; nginx `try_files` serves `.json`) and loaded by
MapLibre GL as local GeoJSON sources, so the map renders **fully offline** — no remote
tiles, glyphs or sprite.

Together they produce a **detailed, coloured** map: a sea backdrop, a lat/long graticule for
depth, filled land with country borders + a coastline accent, and major EU/UK PoP-region city
markers. City **names** are drawn as DOM-overlay labels by the component (same technique as the
cluster-count badges) because MapLibre symbol text needs a bundled glyph stack the basemap
deliberately omits — this keeps text rendering fully offline with no shipped glyphs.

- `europe.json`    — Natural Earth 110m admin-0 country polygons → land fill + borders + coast.
- `graticule.json` — a 5° lat/long grid over the UK/EU viewport (generated from the bbox; no
  external source). ~6 KB.
- `cities.json`    — 12 major EU/UK cities (public-domain centroids, same values Natural Earth
  `ne_110m_populated_places` carries), aligned to the topology geo catalogue. ~1.4 KB.

`graticule.json` and `cities.json` are (re)generated by `scripts/build-geo-extras.mjs`
(`node scripts/build-geo-extras.mjs`) — no network needed.

## How it is generated

Regenerated with the one-off script `scripts/build-europe-basemap.mjs`, which:

1. downloads the source FeatureCollection (network used only at generation time);
2. clips features to the UK/EU viewport bbox `lon[-12, 32] lat[34, 62]`
   (keeps any country with a vertex in the box, so coastlines/borders stay continuous);
3. rounds every coordinate to 3 decimals (~110 m) to keep the payload ~30–90 KB;
4. strips properties to the country `name`.

```sh
curl -sSL -o /tmp/ne_110m.geojson \
  https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson
node scripts/build-europe-basemap.mjs /tmp/ne_110m.geojson public/geo/europe.json
```

Current asset: ~38 KB, 42 country features.
